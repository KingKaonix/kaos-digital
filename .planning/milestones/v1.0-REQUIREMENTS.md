# Requirements: AI Template Generator

**Defined:** 2025-11-23
**Core Value:** Users can describe a website in plain language and get a complete, editable Angular + Bootstrap 5 template back — with saving, editing, and (paid) export.

## v1 Requirements

Requirements for initial release. Each maps to roadmap phases.

### Authentication

- [x] **AUTH-01**: User can sign up with email and password
- [x] **AUTH-02**: User can log in and log out

### Code Generation

- [x] **GEN-01**: User can describe a template in natural language
- [x] **GEN-02**: AI (NVIDIA Nemotron) generates Angular + Bootstrap 5 code from the description
- [x] **GEN-03**: User can preview the generated template
- [x] **GEN-04**: User can edit a saved template's description and regenerate (Phase 3)

### Template Management

- [x] **TPL-01**: User can save a generated template to their account (Phase 3)
- [x] **TPL-02**: User can view their saved templates in a gallery (Phase 3)

### Export (Paywalled)

- [ ] **EXP-01**: Free users can generate and preview templates
- [ ] **EXP-02**: Export (ZIP download or deployable code) is behind a paywall
- [ ] **EXP-03**: Paid users can export templates as ZIP
- [ ] **EXP-04**: Paid users can export deployable Angular code

## v2 Requirements

Deferred to future release. Tracked but not in current roadmap.

### Versioning

- **TPL-03**: User can view version history and roll back to previous template versions

### Editing

- **GEN-05**: User can edit a template via AI-powered chat (modify existing code instead of re-prompting)

### Deployment

- **EXP-05**: Paid users can one-click deploy to Vercel or Netlify

### Auth

- **AUTH-03**: User can log in via OAuth (Google, GitHub)

## Out of Scope

Explicitly excluded. Documented to prevent scope creep.

| Feature | Reason |
|---------|--------|
| Real-time collaborative editing | High complexity (WebSockets, conflict resolution); not core to v1 value |
| OAuth login | Email/password sufficient for v1; can be added later if needed |
| Mobile-native app | Web-first per PROJECT.md; mobile later |
| Real-time AI chat beyond generation | Not core to generation flow; scope creep |
| Video or rich media assets in templates | Storage/bandwidth costs; explicitly out of scope in PROJECT.md |
| Automatic A/B testing | Requires traffic analytics and split-testing infrastructure |
| AI copywriting / content generation | Different model capability; distracts from code generation |
| White-labeling / enterprise SSO | Enterprise sales cycle; not relevant to developer/designer target |
