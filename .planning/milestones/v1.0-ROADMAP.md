# Roadmap: AI Template Generator

## Phases

- [x] **Phase 1: Foundation — Auth + Data Layer** - Users can sign up, log in, and their data is isolated by user; Supabase foundation with no secret keys in the browser.
- [x] **Phase 2: Core — Generation Pipeline + Preview** - Users can describe a template in natural language, receive generated Angular + Bootstrap 5 code, and preview it live.
- [x] **Phase 3: Persistence — Save/Load Templates + Gallery** - Users can save generated templates, view them in a personal gallery, and edit a saved template's description to regenerate it.
- [x] **Phase 4: Monetization — Stripe Paywall + Export** - Free users can generate and preview; paid users can export ZIP and deployable Angular code behind a server-side Stripe paywall.

## Phase Details

### Phase 1: Foundation — Auth + Data Layer

**Goal**: Users can create accounts, sign in, and trust that their data is isolated from other users.
**Mode:** mvp
**Depends on**: Nothing (first phase)
**Requirements**: AUTH-01, AUTH-02
**Success Criteria** (what must be TRUE):
  1. User can sign up with email and password
  2. User can log in and log out, staying signed in across page refreshes
  3. User's data is private — a user cannot view another user's templates or account data
  4. No secret keys (Nemotron, Stripe, Supabase service role) are exposed in the frontend bundle

**Plans**: TBD
**UI hint**: yes

### Phase 2: Core — Generation Pipeline + Preview

**Goal**: Users can describe a template in plain language and see the generated Angular + Bootstrap 5 code previewed live in the browser.
**Mode:** mvp
**Depends on**: Phase 1
**Requirements**: GEN-01, GEN-02, GEN-03
**Success Criteria** (what must be TRUE):
  1. User can enter a natural-language description and submit it for generation
  2. User receives generated Angular + Bootstrap 5 code from Nemotron
  3. User can preview the generated template in a sandboxed iframe
  4. Generated code is valid Angular (standalone components, Bootstrap 5.3)

**Plans**: 5 plans (2.1 Nemotron Serverless Function, 2.2 Generation Client Service, 2.3 Prompt UI, 2.4 Preview, 2.5 Zero-Client-Error Guarantee) — all complete
**UI hint**: yes

### Phase 3: Persistence — Save/Load Templates + Gallery

**Goal**: Users can save generated templates to their account, view them in a personal gallery, and edit a saved template's description to regenerate it.
**Mode:** mvp
**Depends on**: Phase 1, Phase 2
**Requirements**: TPL-01, TPL-02, GEN-04
**Success Criteria** (what must be TRUE):
  1. User can save a generated template to their account
  2. User can view their saved templates in a personal gallery
  3. User can edit a saved template's description and regenerate the code
  4. User only sees their own templates in the gallery (user isolation)

**Plans**: 5 plans (3.1 Templates Service CRUD, 3.2 Save Button on Generation Page, 3.3 Gallery Page (Cards View), 3.4 Template Actions (Edit/Delete/Duplicate/Rename), 3.5 Edit & Regenerate Flow) — all complete
**UI hint**: yes

### Phase 4: Monetization — Stripe Paywall + Export

**Goal**: Free users can generate and preview templates, while paid users can export ZIP and deployable Angular code behind a server-side Stripe paywall.
**Mode:** mvp
**Depends on**: Phase 1, Phase 2, Phase 3
**Requirements**: EXP-01, EXP-02, EXP-03, EXP-04
**Success Criteria** (what must be TRUE):
  1. Free users can generate and preview templates without paying
  2. Export actions are blocked for free users with a paywall upsell
  3. Paid users can download a generated template as a ZIP file
  4. Paid users can download deployable Angular project code
  5. Paywall is enforced server-side — cannot be bypassed via frontend flags

**Plans**: 5 plans (4.1 Stripe Integration & Customer Management, 4.2 Entitlement Middleware (Server-Side Paywall), 4.3 ZIP Export, 4.4 Deployable Angular Project Export, 4.5 Paywall UI & Pricing) — all complete
**UI hint**: yes
